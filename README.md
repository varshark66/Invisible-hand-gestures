AI-Based Invisible Hand for Disabled People
A hands-free, AI-powered computer control system that enables physically disabled users to interact with digital devices using facial gestures.

📌 Project Summary:

This project proposes an innovative gesture-based interface that uses facial gestures like eye blinks, head tilts, and mouth movements to control a computer without using hands or expensive external hardware. Designed for users with physical impairments, the system leverages computer vision and AI to provide real-time, touch-free digital accessibility.

📌Objectives:

Enable hands-free mouse operations through facial gestures

Ensure affordability and ease of use (only a webcam required)

Promote accessibility for users with physical/motor disabilities

Leverage AI and temporal logic to recognize intentional gestures
